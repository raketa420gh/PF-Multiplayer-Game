# Balance

Баланс хранится как измеримые параметры, а не только как ощущения.

## Core KPIs
- Extraction rate
- Death rate
- Average raid duration
- Average loot value
- Gear loss rate
- PvP kills per raid
- PvE kills per raid
- Average time-to-first-combat
- Average time-to-extraction

## Rule
Каждое изменение баланса должно иметь причину и ожидаемый эффект.
