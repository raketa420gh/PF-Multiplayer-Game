# HUD

## Required Information
- HP
- Stamina
- Currently equipped weapon/item
- Active hand / attack input context when needed
- Ammo
- Quest/objective
- Team status
- Interaction prompt
- Extraction state
- Important status effects

## Combat Feedback
HUD itself should remain minimal; combat readability primarily comes from first-person hands, weapon animation, audio and impact feedback.

Optional/contextual feedback:
- current weapon;
- block state;
- temporary block recovery / inability to block;
- combo continuation feedback, if testing shows it is necessary.

## Information Priority
1. Immediate survival
2. Combat state
3. Team state
4. Objectives
5. Navigation
