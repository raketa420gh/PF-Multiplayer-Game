# Game Vision

## High Concept
PvPvE extraction game от первого лица на Unity с Photon Fusion. Игроки входят на опасную карту соло или отрядом до трёх человек, исследуют локации, сражаются с PvE и другими игроками, добывают ценные предметы и пытаются успешно эвакуироваться.

## Combat Identity
Бой строится вокруг физически читаемого first-person melee combat: оружие определяет набор атак и анимаций, атаки выполняются сериями с timing-окнами продолжения, а блок зависит от пространственного угла столкновения. Видимые руки, оружие и верхняя часть тела должны давать игроку большую часть непосредственной боевой информации.

## Player Goal
Зайти на карту → добыть ценности / выполнить задачи → пережить PvP и PvE угрозы → эвакуироваться → сохранить добычу → улучшить персонажа и снаряжение → повторить рейд.

## Death
При смерти игрок теряет весь вынесенный в рейд инвентарь и экипировку согласно правилам экономики игры.
