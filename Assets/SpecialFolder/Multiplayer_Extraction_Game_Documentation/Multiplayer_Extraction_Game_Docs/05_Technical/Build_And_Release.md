## Build Pipeline
- Content: generated by editor builders (DD-008).
- Dedicated server: `Tools/Game/Network/Build Dedicated Server` → `Builds/DedicatedServer/DungeonServer.exe` (StandaloneWindows64, all enabled scenes); logs per session next to it (`Tools/Game/Network/Open Server Logs`).
- Server launch (dev orchestrator `LocalServer`): `DungeonServer.exe -batchmode -nographics -dedicatedServer -session <name> -mode <QueueMode> -floor <n> -logFile <session>.log`. Release target: a real orchestrator allocating servers with the same arguments.
- The server build must match the client scenes and code: an older build gives Fusion "Behaviour count mismatch" on scene NetworkObjects. In the editor `LocalServer` detects a stale build and falls back to Host — rebuild the server after any scene/code change.
