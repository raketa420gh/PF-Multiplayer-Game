# Multiplayer Extraction Game — Documentation

Документация проекта разделена по доменам. **GDD отвечает на вопрос «что и зачем», техническая документация — «как», задачи — «что сделать».**

## Current Version
**GDD v0.3** — обновлено 2026-10-02.

Основное новое изменение: детализирована first-person боевая модель — управление гуманоидом, независимый upper-body pitch, crouch, видимые руки, weapon-driven animation, input mapping по рукам, attack chains и directional/partial blocking.

## Структура
- `01_Master_GDD` — видение и основные циклы.
- `02_Gameplay` — управление, бой, классы, инвентарь, прогрессия.
- `03_World` — карта, PvE, лут, extraction.
- `04_Multiplayer` — Photon Fusion и сетевые правила.
- `05_Technical` — архитектура Unity и инженерные правила.
- `06_Art` — визуальные требования.
- `07_Audio` — звук.
- `08_UI_UX` — интерфейс.
- `09_Balance` — баланс.
- `10_Analytics` — аналитика.
- `11_QA` — тестирование.
- `12_Roadmap` — этапы разработки.
- `13_Decision_Log` — зафиксированные решения.
