# Задача: механика смерти — локальный рагдолл и лут тела (как в Dark and Darker)

Статус: **сделано** 2026-10-18 (п. 1–8; п. 9 — монстры — отдельной задачей). Риг — `BattleRagdollBuilder` (слой `Ragdoll`),
рантайм — `RagdollComponent`, тело — `CorpseComponent`; серверная задержка лута 1 с (`_lootDelay`), поздний вход в клоне не проверялся.

## Цель

Игрок умирает → тело сразу обмякает в рагдолл и падает по физике с учётом инерции и удара, которым убили.
Рагдолл **у каждого клиента свой, не сетевой** (позы на разных клиентах могут отличаться — это нормально, как в DaD).
Когда тело упало и остановилось — физика выключается, тело замирает в итоговой позе и его можно лутать.

## Как в Dark and Darker (эталон поведения)

- Анимации смерти нет: в момент смерти — мгновенный переход из текущей анимационной позы в рагдолл,
  без кроссфейда, с сохранением скорости движения (бег, прыжок, падение с высоты продолжаются телом).
- Добивающий удар толкает тело по направлению удара (рубящий — вбок, колющий/стрела — назад), умеренно, без «полёта».
- Оружие и броня остаются на теле (броня скиннированная, оружие в руке — едет вместе с костью кисти).
- Тело падает естественно: ступеньки, края, стены; суставы не выворачиваются, конечности не проходят сквозь пол.
- После остановки тело неподвижно навсегда; игроки и монстры сквозь него проходят, не спотыкаются и не толкают его.
- Лутается взглядом на любую часть тела (не на невидимую коробку у ног), подсказка «Loot» + имя убитого.
- Тело лежит до конца матча, инвентарь — полный (как сейчас `CorpseComponent.Setup`).
- Умерший видит своё тело со стороны (камера смерти), затем экран смерти/наблюдение — текущий поток `OnDied` не трогаем,
  только камера на время падения.

## Что сделать

1. **Рагдолл-риг (editor).** Генерировать коллайдеры/`Rigidbody`/`CharacterJoint` по humanoid-костям модели
   (бёдра, позвоночник, грудь, голова, плечо/предплечье, бедро/голень — 11 тел, как стандартный Ragdoll Wizard),
   массы по долям тела, лимиты суставов анатомические. Делать в `BuildCorpse` (и общим методом для монстров позже),
   а не руками в префабе — переживает пересборку. По умолчанию всё `isKinematic`, коллайдеры выключены.
2. **Слой `Ragdoll`.** Сталкивается только с геометрией уровня (и сам с собой — по желанию); не с игроками,
   CharacterController, Fusion-хитбоксами, триггерами, снарядами. Проверить Physics-матрицу.
3. **Старт рагдолла на каждом клиенте.** В `CorpseComponent.Spawned`: если исходный адвенчурер есть у клиента —
   скопировать мировые позы всех костей с его модели (локальный рендер, не сеть), выключить его модель
   (у владельца — включить полное тело, FP-руки скрыть), выключить аниматор тела, включить физику.
   Начальная скорость каждого тела = скорость персонажа (`Move.Velocity`) + импульс удара.
   Для этого в сеть идут только данные момента смерти: направление и сила добивающего удара, скорость — поля
   `CorpseComponent` (`[Networked]`, ставит сервер в `SpawnCorpse`), сама физика — нет.
4. **Поздний вход / тело вне зоны интереса.** Если адвенчурера уже нет — тело стартует из позы `Death`
   (как сейчас) и сразу считается упавшим (или короткий рагдолл без импульса — решить по виду).
5. **Остановка.** Settle = все `Rigidbody` спят **или** макс. скорость < ~0.05 м/с в течение ~0.5 с, жёсткий таймаут ~6 с.
   После — `isKinematic = true`, коллайдеры костей переводятся в режим «только для взгляда» (слой интеракции, без физики),
   компонент перестаёт тикать. Анти-баги: тело улетело под пол / дальше N м от точки смерти → вернуть к точке смерти в позу Death.
6. **Лут.** Убрать фиксированный бокс у ног; цель интеракции — коллайдеры костей рагдолла (рейкаст клиента).
   Доступность — два условия: клиент — локальный рагдолл остановился (показывать подсказку только тогда);
   сервер — прошло T с момента смерти (`[Networked] DeathTick` + конфиг, T ≈ таймаут остановки) и дистанция до
   точки смерти ≤ радиуса с запасом на расхождение поз между клиентами. Сервер позу рагдолла не знает — не полагаться на неё.
7. **Адвенчурер.** С появлением рагдолла убрать проигрывание `Death` у живой модели (не две модели), деспаун 2.5 с оставить.
8. **Камера смерти.** У владельца на время падения — камера от третьего лица на тело (плавно из FP), затем текущий поток.
9. **Монстры — отдельная задача, здесь не делать.** Тот же рагдолл для гуманоидных монстров вместо `Death`-анимации; лут — по костям после остановки.
   Негуманоидов (летающая голова и т.п.) не трогать.

## Ограничения

- Физика рагдолла — только локально, без `NetworkRigidbody`/`NetworkTransform` на костях, без RPC с позами.
- Dedicated server (headless) рагдолл не симулирует.
- Броня/оружие на теле работают через тот же `ArmorDresser`; skinned-меши должны рендериться при отключённом аниматоре.
- Без `Find*`-API; ссылки на кости — сериализованные (заполняет билдер).
- Пересборка `DungeonContentBuilder` должна давать тот же риг (см. `battle-asset-pipeline`).

## Решения пользователя (2026-10-18)

- Лут — **сразу после остановки**, без дополнительной задержки (серверное T = только таймаут остановки, не больше).
- После остановки поза **застывает навсегда**: удары и прочее тело не двигают.
- Камера смерти — **третье лицо** на своё тело.
- Монстры — **отдельной задачей**, п. 9 в эту не входит.

## Проверка

`Game.Scripts.Editor.RebuildVerify.Run("Dungeon")`, затем в плей-моде (хост + клон ParrelSync): убить адвенчурера
на ровном полу, на лестнице и в прыжке — тело падает из текущей позы с инерцией и импульсом удара, кости не проходят
сквозь пол, суставы в лимитах; через ≤ 6 с все `Rigidbody` кинематические; подсказка «Loot» появляется при взгляде
на любую кость; сервер отказывает в луте до T и вне радиуса; на клиенте и хосте позы различаются, но лут работает у обоих;
поздний вход видит тело в позе Death.
