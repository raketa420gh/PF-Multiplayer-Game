**Правило:** этапы идут строго по порядку. Следующий начинается, только когда выполнен Definition of Done предыдущего.

| # | Этап | Статус |

## Этап 1. Черновые локации

**Статус 2026-11-03:** черновики всех комнат пользователь принял как готовые. Открытые пункты (1.3, 1.6, 1.8, реестр) теперь доводка: делаем фоном или между задачами, следующие этапы они не блокируют.

**Что на выходе:** этаж 7×7 без повторов (DD-025) собирается из одних блокаутов, по нему можно пройти от любой комнаты до любой другой.

**В черновике только геометрия:** стены, полы, перепады, лестницы, ямы, вода, сигнатурная механика комнаты. Без декора, лута и мобов. Свет — только чтобы видеть геометрию.
