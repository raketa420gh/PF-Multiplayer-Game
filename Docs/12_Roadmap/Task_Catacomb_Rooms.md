# Задача: комнаты катакомб по макетам и два проёма на сторону

**Статус:** выполнена (2026-10-09), кроме плей-теста через лобби; `DungeonServer.exe` пересобран · **Ветка:** `special` · **Связано:** DD-020, `03_World/Map_Design.md`

## Цель
Перенести в игру комнаты из веб-макетов `Tools/RoomLayouts/index.html` и перевести «Запутанные катакомбы» с одного проёма в середине стороны на **два проёма на каждой стороне**. Угловые клетки сетки 7×7 получают отдельные угловые комнаты.

## Вход
1. **Выбор комнат.** Пользователь оценивает макеты на странице (✔ / ✎ / ✖ + заметка) и присылает итог кнопкой «Скопировать итог» или файлом `catacomb-room-choice.json`.
   - ✔ — переносим как есть.
   - ✎ — сначала правим макет на странице, показываем, потом переносим.
   - ✖ — не делаем.
   - Пока выбора нет, задачу не начинать: шаги 1–2 ниже от выбора не зависят и могут идти первыми.
2. **Данные макетов** — массив `ROOMS` на странице. Система координат совпадает с Unity и `CatacombRoomBuilder`:
   - x — восток, z — север, метры от центра комнаты;
   - yaw — по часовой, как `Quaternion.Euler(0, yaw, 0)`.
   
   Координаты переносятся без пересчёта.

## Геометрия (общая для всех комнат)
- Клетка — 34,2 м (комната 33,6 м + общая стена 0,6 м), высота 6 м. Проём 3 × 3,4 м.
- **Проёмы:** по два на сторону, в серединах половин стены — смещение ±8,4 м (`H/2`) от центра стороны.
- **Обычная комната:** 8 проёмов, поворот на любую четверть.
- **Угловая комната** (`corner`): проёмы только на северной и восточной сторонах, южная и западная стены глухие. Ставится только в 4 угла сетки и поворачивается так, чтобы глухие стороны смотрели наружу. В юго-западном углу поворот 0°, в остальных углах — кратный 90°.
- Все проёмы комнаты связаны между собой (страница проверяет это сама). Зона 3 × 2,5 м перед каждым проёмом свободна; единственное допустимое исключение — мостки +0,25 м.

## Шаги

### 1. Генератор и стены — `CatacombGenerator`, `CatacombRoomBuilder`
- Префабы стороны клетки: вместо `CatacombWall` / `CatacombDoorway` нужна сторона с двумя проёмами, в которой каждый проём может быть открыт или закрыт. Это либо 4 варианта префаба (оба открыты / левый / правый / оба закрыты), либо сегменты стены плюс заглушки на проёмах.
- `Plan`: вместо `bool East/North` на сторону — состояние каждого из двух проёмов.
- Остовное дерево (DFS) открывает на ребре хотя бы один проём, второй открывается с вероятностью `_loops`. Внутри комнаты все проёмы связаны, поэтому связность этажа сохраняется.
- Внешний край сетки — глухая стена, как сейчас.
- Угловые клетки берут комнату только из пула угловых. Обычные клетки — только из пула обычных, в том числе у края: проёмы наружу там закрыты внешней стеной.
- Ключевая комната (Великий зал в центре) тоже переходит на два проёма на сторону: перестроить её стены в `DungeonMapBuilder`, отодвинуть пропсы от новых проёмов, проверить 4 портала побега.
- Стыковка карты и миникарты (`Map`, `_cellPixels`, сшивка текстур клеток) — проёмы на новых местах.

### 2. Маркеры — `CatacombRoomComponent`
- Флаг `IsCorner`.
- **Тип монстра на точке** (сейчас точки безтиповые и берут случайный вид из `DungeonDirector._monsters`). Нужно поле вида: Мечник / Лучник / Арбалетчик / Воин со щитом / Маг / Летучий череп / любой.
  - Есть только `SkeletonSwordsman`, `SkeletonArcher`, `SkeletonWarrior`.
  - Пока Арбалетчика, Мага и Черепа нет, их точки берут ближайшего существующего: Арбалетчик → Лучник, Маг → Лучник, Череп → Мечник. Каждая такая точка помечается для замены, когда монстр появится (ростер DD-016).
- Контейнеры сопоставить с префабами:
  - Богатый сундук → `GoldenChest`;
  - Большой → `LargeOakChest`;
  - Малый → `SmallOakChest`;
  - Гроб → `Coffin`;
  - Полка → `Bookshelf`;
  - Бочка → `Barrel`;
  - Ящик → `Crate`;
  - Урна — префаба нет: сделать новый или временно заменить на `Crate`.
- Ловушки: Шипы → `SpikeTrap`, Маятник → `BladeTrap`.
- Свет: Факел → `HallTorch`, Свечи → `CandleCluster`, Жаровня → `Brazier`. Ещё нужны: костёр/очаг, свет из пролома (холодный spot сверху), зелёное свечение котла.
- «Тёмные зоны» на макете — это намерение дизайна. В игре их обеспечивает отсутствие света, отдельного объекта не нужно.

### 3. Билдер комнат — `CatacombRoomBuilder`
- По одному методу на выбранную комнату. Позиции блоков, пропсов, маркеров и света переносятся из `ROOMS` один в один.
- Помощники на странице и в билдере называются похоже, это упрощает перенос:

  | На странице | В билдере |
  |---|---|
  | `B` / `C` | `Block` |
  | `L` | `Prop` / `Block` |
  | `M` | `Monster` |
  | `K` | `Container` |
  | `T` | `Trap` |
  | `TO` | `Torch` |
  | `S` | `Starts` |

- Новые элементы геометрии:
  - **Возвышения и лестницы** (`PL`, `ST`): уступы ≤ 0,25 м или ≥ 1 м; лестницы — визуальные ступени + скрытый выпуклый пандус (правило NavMesh, см. level-design-rules).
  - **Ямы** (`P`): провал в полу со стенками; «Пропасть» 12 м — падение = смерть, «Провал» 3 м и «Костяная яма» 4 м — урон от падения по существующей механике или без урона, решить при реализации.
  - **Вода** (`W`): поверхность + зона замедления. Механики замедления пока нет — завести её или убрать воду из «Цистерны».
  - **Решётки** (`BA`): блокируют проход, но не свет и не стрельбу.
- Вес и лимит каждой комнаты (`Weight` / `Limit`) задаются при переносе. Старые 8 комнат удаляются целиком, потому что все комнаты переделаны.
- Миникарта: стены называть `Wall*`, потолок `Ceiling*`. Ямы и вода должны быть видны на карте.

### 4. Сборка и проверка
- `Tools/Game/Dungeon/Build All` (или частичная пересборка контента и сцены), затем `RebuildVerify.Run("Dungeon")`.
- Проверить на 3–5 сидах:
  - каждая клетка достижима по NavMesh, который печёт хост;
  - мобы с лестниц спускаются и поднимаются;
  - в угловых клетках стоят только угловые комнаты, и глухие стороны смотрят наружу.
- Плей-тест: пройти от старта до каждого угла, проверить ловушки, ямы, освещение (тёмные зоны действительно тёмные), лут в контейнерах.
- Пересобрать серверную сборку `DungeonServer.exe`.
- Обновить `Map_Design.md`, записать решение в `Decision_Log.md` (два проёма на сторону, угловые комнаты).

## Критерии приёмки
- В игре есть все комнаты, помеченные ✔, и поправленные ✎. Их раскладка совпадает с макетом.
- В каждой стороне клетки два проёма. На каждом ребре между соседями открыт хотя бы один, весь этаж связан.
- Угловые клетки — только угловые комнаты с глухими сторонами наружу.
- Монстры, контейнеры, ловушки, свет и старты стоят по маркерам. Подстановки отсутствующих монстров перечислены в отчёте.
- `RebuildVerify` без ошибок, плей-тест на нескольких сидах пройден.
