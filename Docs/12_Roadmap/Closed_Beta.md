# Closed Beta Test (CBT)

Что должно быть готово к закрытому бета-тесту. Фаза — Beta (`0.6.x`), см. `README.md`.

## Must Have

### Сеть
- [ ] Рабочая сетевая игра на dedicated server

### Персонаж
- [ ] Все механики персонажа с анимациями: перемещение, действия и т. д.

### Классы
- [ ] 6 классов × 3 подкласса
- [ ] Базовый набор перков, скиллов и спеллов

### Подземелье
- [ ] Модульное подземелье 5×5 (DD-024)
- [ ] 25 уникальных локаций (каждая — один раз за забег)
- [ ] Базово проработанный левел-дизайн (без финальной полировки)

### PvE-враги
- [ ] Нежить-скелеты: мечник, лучник, арбалетчик, маг, летающий череп
- [ ] Минибоссы — 2 шт. (TBD, ещё не придуманы)
- [ ] Моб-скример: кричит и привлекает внимание, если начать его лутать
