# Roadmap

Roadmap должна описывать проверяемые результаты, а не только список фич.

## Phases
| # | Фаза | Stage | Ориентир версии |
|---|---|---|---|
| 1 | Prototype | Pre-Alpha | `0.1.x` |
| 2 | Core Multiplayer Prototype | Pre-Alpha | `0.2.x` |
| 3 | Vertical Slice | Pre-Alpha | `0.3.x` |
| 4 | Alpha (closed → open) | Alpha | `0.4.x`–`0.5.x` |
| 5 | Beta | Beta | `0.6.x`–`0.7.x` |
| 6 | Early Access | Early Access | `0.8.x`+ |
| 7 | Release Candidate | Release Candidate | `0.9.x` |
| 8 | Release | Release | `1.0.0` |

Каждая фаза должна иметь Definition of Done.

## Stages
- **Pre-Alpha** — игра собирается как система: много прототипов, механики могут исчезать целиком.
- **Alpha** — основные механики есть, но игра нестабильна и активно меняется.
- **Beta** — основные механики определились; фокус — баланс, баги, UX, производительность.
- **Early Access** — игра доступна игрокам в Steam, разработка продолжается.
- **Release Candidate** — если критических проблем не найдено, этот билд становится релизом.
- **Release (1.0)** — первый полноценный релиз; дальше обновления, патчи, DLC.

Alpha ≠ плохая игра, Beta ≠ почти готовая игра: стадия описывает, насколько стабилизировалась разработка. Правила версий — `05_Technical/Build_And_Release.md`, DD-018.
