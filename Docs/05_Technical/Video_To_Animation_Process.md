# Video → Weapon Animation: журнал процесса

Цель: пройти пайплайн «видеореференс → анимация оружия» вручную, шаг за шагом, фиксируя проблемы и решения. По итогам — собрать скилл `.claude/skills/video-to-animation` (старый удалён в `a939b726`).

## Окружение

- Python 3.13 (`py`), `opencv-python-headless` 5.0, `numpy` 2.5. ffmpeg нет.
- Референсы: пользователь кладёт в `D:\` (`*.mp4` или папки вида `D:\arming_sword_refs`).
- Рабочие файлы (кадры, листы, отчёты) — scratchpad сессии, не в репо.

## Шаги пайплайна (черновик, уточняется по ходу)

1. **Приём референса** — путь, длительность, fps, разрешение, ракурс (FP / сбоку / сверху), скорость (1x / замедление).
2. **Раскадровка** — извлечь кадры, собрать контакт-листы, найти ключевые фазы (idle → windup → peak → follow-through → recovery).
3. **Чтение позы по кадрам** — на ключевых кадрах: плечо/локоть/кисть, хват, направление клинка, корпус, ноги.
4. *(далее — по мере прохождения)*
