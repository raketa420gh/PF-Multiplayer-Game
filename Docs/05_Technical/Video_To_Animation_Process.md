# Video → Weapon Animation: журнал процесса

Цель: пройти пайплайн «видеореференс → анимация оружия» вручную, шаг за шагом, фиксируя проблемы и решения. По итогам — собрать скилл `.claude/skills/video-to-animation` (старый удалён в `a939b726`).

## Окружение

- Python 3.13 (`py`), `opencv-python-headless` 5.0, `numpy` 2.5. ffmpeg нет.
- Референсы: пользователь кладёт в `D:\` (`*.mp4` или папки вида `D:\arming_sword_refs`).
- Скрипты: `tools/video_to_animation/` (см. ниже). Рабочие кадры/листы — scratchpad сессии, не в репо.
- Страница сравнения: `D:\arming_sword_refs\compare\index.html` (вне репо, ~200 МБ кадров).
- Отчёты чтения рефа: `D:/arming_sword_refs/reports/` (A1, A2, A3, R, FP .md).

## Шаги пайплайна (черновик, уточняется по ходу)

1. **Приём референса** — `ffprobe`-аналог через OpenCV: fps, кадры, разрешение. Обзорный лист раз в 1.5 с (`sheet.py`) → понять структуру видео (какие атаки, ракурсы, где замедление).
2. **Сегментация** — `cuts.py`: склейки по среднему разностному кадру (порог 25 на 96×54). `slow.py`: диапазоны с жёлтой надписью «0.1x Speed» (правый верх). Итог — таблица «атака × ракурс → диапазон кадров».
3. **Раскадровка** — `sheet2.py` (лист диапазона с шагом, кроп, гамма, метка SLOW) и `frames.py` (крупные кропы выбранных кадров, ≥600 px). Сначала лист, потом крупно ключевые кадры.
4. **Чтение позы** — по брифу `BRIEF.md`: тайминг в реальных кадрах, позы по фазам в root-space (м, +Z вперёд, +X вправо), траектория кончика, пик относительно глаз, хват, уверенность. Одна атака — один субагент, параллельно; проверять их выводы глазами на крупных кропах.
5. **Варианты в спеке** — временный статический переключатель варианта в `DungeonWeaponLibrary` (только превью), позы через `At/Peak/Via/Cm`; после выбора удаляется.
6. **Рендер нашего персонажа** — `SwingPreview.Run(prefix, swing, views, frames, folder, size)` через reflection в `execute_code`; свободная камера `c_x_y_z_tx_ty_tz_fov` подогнана под ракурсы рефа.
7. **HTML-сравнение** — `refseq.py` режет реф в реальное время (0.1x-участки — каждый 10-й кадр), `index.html` — плеер: ряды рефа и вариантов, синхронизация по пику, ползунок/скорость.

## Наблюдения по Arming Sword (`D:\arming_sword_refs\arming_sword.mp4`)

- Видео: 0–11 с — показ хитбокса меча; далее Attack #1, #2, #3, Riposte, по 4 ракурса каждая: A (спереди), B (справа-спереди), T (сверху, наклон ~20–25°), D (как B + хитбокс, активная фаза в 0.1x).
- Наш `Footage = 0.75·Frame`: наши клипы = 0.75 длительности рефа (форхенд: реф ~86 кадров, наш клип 72). В плеере есть галочка «ужать реф до нашего темпа».
- **3P vs FP у DaD различаются**: в 3P-виде пик — прямая рука на уровне плеча (кисть ~1.40–1.45 м, кончик ниже глаз); в FP-видео (`arming_sword_all_attacks.mp4`) кулак в пике проходит через прицел. Отсюда два варианта: «как 3P» и «как FP».
- `arming_sword_all_attacks.mp4` — FP, вся связка Attack #1→#2→#3 (1x, затем повтор 0.5x): A1 f110–140, A2 f150–190, A3 f225–320. `arming_sword_all_attacks_2.mp4` — 3P другого игрока, тёмное, не использовалось.
