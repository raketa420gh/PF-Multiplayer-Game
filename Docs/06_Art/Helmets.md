# Helmets — исторические шлемы (справка)

Пища для ума, не план: какие шлемы делать, ещё не решено. Только исторически верные европейские и русские шлемы V–XV вв. Close helm и бургиньот — уже XVI в. (Ренессанс), сюда не входят.

## Хронология

| Шлем | Период | Вид |
|---|---|---|
| Spangenhelm | V–VIII вв. | Купол из 4–6 пластин на клёпаном каркасе-полосах, иногда нащёчники и бармица |
| Вендельский / Gjermundbu | VI–X вв. | Купол с гребнем и «очками» вокруг глаз; Gjermundbu — единственный почти целый шлем эпохи викингов |
| Нормандский (конический с наносником) | X–XII вв. | Конус, цельнокованый или сегментный, прямая пластина на нос |
| Русский шелом (шишак) | X–XIII вв. | Высокий вытянутый купол со шпилем, бармица до плеч, иногда полумаска или наносник |
| Шапель (kettle hat) | XII–XV вв. | «Каска» с широкими полями; пехота и стрелки |
| Цервельер | XIII в. | Полусферическая шапка, под кольчужный капюшон или топхельм |
| Топхельм с плоским верхом (pot helm) | ~1200–1250 | Цилиндр с плоской крышкой, смотровая щель, дыхательные отверстия |
| Сахарная голова (sugarloaf) | ~1270–1350 | Топхельм с округлённо-конической макушкой, поверх цервельера |
| Бацинет с бармицей | XIV в. | Заострённый купол, лицо открыто, кольчужная бармица на плечи |
| Hounskull («собачья морда») | ~1380–1420 | Бацинет с коническим забралом-«клювом» на шарнирах |
| Большой бацинет | ~1400–1450 | Закрытый, крепится к кирасе, голова не поворачивается |
| Барбют | ~1400–1470 | Итальянский закрытый с T/Y-вырезом для лица |
| Салад + бувигер | ~1430–1500 | Немецкий, длинный хвост-назатыльник, смотровая щель; бувигер закрывает подбородок |
| Армэ | ~1420–1500 | Итальянский закрытый, раскрывающиеся нащёчники, подвижное забрало |

## По ролям

| Роль | Шлемы | Почему |
|---|---|---|
| Лучник | Цервельер, шапель, spangenhelm | Тетива идёт к щеке, нащёчники и забрало мешают; шапель — исторически шлем стрелков |
| Разбойник / разведчик | Цервельер, нормандский, Gjermundbu | Лёгкие, не режут обзор и слух |
| Маг / жрец | Цервельер, бацинет с бармицей без забрала, шапель | Открытое лицо |
| Лёгкий воин / наёмник | Нормандский, шишак, бацинет с бармицей, барбют | Баланс защиты и обзора |
| Пехотинец / латник | Салад + бувигер, барбют, шапель + бувигер | Пехота XV в. |
| Тяжёлый воин / рыцарь | Топхельм, сахарная голова, hounskull, большой бацинет, армэ | Полностью закрытые |

## Идея тиров лута

- T1: цервельер, spangenhelm
- T2: шапель, нормандский, Gjermundbu
- T3: шишак, бацинет с бармицей, барбют
- T4: топхельм, сахарная голова, салад + бувигер
- T5: hounskull, большой бацинет, армэ

Возможная цена за защиту: закрытые шлемы (T4+) сужают обзор рамкой по краям экрана и приглушают звук, чтобы лёгкие шлемы оставались осмысленным выбором и в позднем луте.

## Генерация референсов

Для трёх видов (перед / бок / зад) проще всего цельные силуэты: барбют, салад, нормандский, топхельм. Кольчужную бармицу нейросеть рисует плохо, её всё равно моделить отдельно.
