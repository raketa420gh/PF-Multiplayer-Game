Перестрой комнату катакомб Alchemy Lab (`Assets/Game/Prefabs/Dungeon/Catacombs/AlchemyLab.prefab`) по утверждённому макету `Docs/LevelMockups/AlchemyLab.html` (он же https://claude.ai/artifact/19Ndryz2CXRbk4NMTneDgH, версия 2).

Источник истины — JSON в строках `const OBJS = …`, `const SHELL = …`, `const BRIDGE = …` этого HTML. Координаты в нём уже в Unity (+Z = север, room-local, центр комнаты 0,0,0): `p` — позиция pivot (низ по центру), `s` — размер X×Y×Z, `ry` — yaw в градусах. Лестницы (`stairs`): pivot в центре основания, подъём вдоль локальной +Z, `s[1]` — высота подъёма. Кислота (`acid`): поверхность на y −0.1, дно рва — `floor` с note «дно рва» (верх −0.25). `light` — точечные источники (`kind`, `color`, `i`, `r`). `shell` (наружные стены с дверьми на ±8.4) и `upper` генерирует комната — не дублировать. `bwall` — стены главного здания (0–12 м, до потолка).

Что изменилось относительно текущего префаба:
1. NW-комната с рычагом: дверной проём в южной стене прямо перед лестницей S2 (x −16.8…−14.4), W2 удалена, восточная стена W9 сдвинута на x −13.2 → под антресолью проход между W- и N-коридором, колонна-опора на (−10.85, 0, 10.85).
2. Ров — кольцо 2.5 м между ±8 и ±10.5 (было ±5…±7.5), разрезан N/S-переходами по x=0 (в зоне урона) и восточным крылом; плюс ниша кислоты 2.6×2.6 у NW-угла здания под балконом.
3. Главное здание ±8 м на всю высоту 12 м: атриум с котлом на полу, галерея 1 (4.3 м, П-образная, лестница с пола у западной стены), галерея 2 (8.3 м, Г-образная, лестница с южной части галереи 1), колонны атриума, парапеты, входы N/S на земле. Балкон над нишей (4.3 м) с дверью в галерею — сюда опускается мост.
4. Восточное крыло x 8…16.8, z ±3.9, высота 8.3: перекрывает восточный коридор (нет прямого прохода между дверьми E z=±8.4), из коридора недоступно, вход только из здания на трёх уровнях (проёмы в стене E), внутри сундук, крыша-терраса с парапетами.
5. Мост B1: шарнир (−10.5, 4.3, 10.5), ry 135, длина 5 м (было 8.7). Сундук X1 на галерее 2, пропсы SE перенесены в угол за рвом, балка D1 / подвес D10 / цепи K3–K4 удалены, свет переставлен.

Требования:
- Префаб и кит user-owned: правь сам префаб (KitBlock/KitStairs из `Prefabs/Dungeon/Catacombs/Kit`), не перегенерируй комнаты из `CatacombRoomLayouts`. В префабе есть незакоммиченные правки пользователя — сохрани всё, что макет не трогает (маркеры монстров/лута/старта, материалы, ручные правки).
- `AcidMoat` (DungeonContentBuilder.BuildAcidMoat): зона сейчас 15×15 (`_halfExtents` 7.5) — расширь под новое кольцо (10.5) так, чтобы пол здания, крыла и коридоров оставался безопасным; проверь, что тела на полу (y 0) не получают урон.
- `BridgeLever` (BuildBridgeLever, `length = 8.4f`) — мост должен быть 5 м и ложиться на балкон; не сломай другие комнаты, если префаб общий.
- Учитывай level-design-rules из памяти (высоты ступеней vs NavMesh, двери, затухание света, материалы кита, имена для миникарты); миникарта комнаты должна перерендериться.
- Проверь NavMesh-связность: ворота N/S → здание → галереи → крыло; восточный коридор разрезан; W- и N-коридоры соединены под антресолью.
- Проверка: `Game.Scripts.Editor.RebuildVerify.Run("Dungeon")`, затем `Verify`; 1 скриншот сверху для сравнения с макетом.
