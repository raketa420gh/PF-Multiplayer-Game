# Progression

Решено 2026-11-13. Вайпов нет — прогресс персонажа навсегда.

## Принципы
- Уровень не даёт сырой силы: атрибуты (сумма 90), HP и урон от уровня не растут. Уровень открывает только слоты и подклассы.
- Новичок учит базу класса на общих навыках/перках, подкласс — середина игры и позже.
- Что-то открывается каждые 5 уровней (25/35/45 — пока пусто).

## Unlocks
| Ур. | Открывается |
|---|---|
| 1 | 1 слот перка, 1 слот навыка (Q); только общие навыки, перки, заклинания (`Subclass = -1`) |
| 5 | 2-й слот перка |
| 10 | 2-й слот навыка (E); у кастера — второе колесо |
| 15 | 3-й слот перка |
| 20 | 4-й слот перка — все слоты |
| 30 | Подкласс I |
| 40 | Подкласс II |
| 50 | Подкласс III, кап |

- Код: `ClassConfig.PerkCountForLevel` / `SkillSlotCountForLevel` / `SubclassCountForLevel` (таблицы `s_perkSlotLevels`, `s_skillSlotLevels`, `s_subclassLevels`).
- У каждого класса 5 общих перков (2 добавлены под эту прогрессию), так что выбор есть до подкласса.

## Spells
- Ограничение только колесом: навык-память в слоте открывает колесо, все 5 слотов колеса открыты всегда.
- До подкласса в колесо идут только общие заклинания; после — все заклинания открытых подклассов. По уровням заклинания не открываются.

## Subclasses
- Подклассы открываются по одному в выбранном игроком порядке: на 30-м первый, на 40-м второй, на 50-м третий.
- Переключение между открытыми — бесплатно, в лобби. Выбор нового — клик по вкладке, пока уровень позволяет ещё один.
- Без подкласса — `Subclass = ClassConfig.NoSubclass` (255). Открытые — `PlayerSessionComponent.SubclassMask`, хранится в старшем байте ключа `subclass`.
- Смена класса сбрасывает подклассы (выбор заново, пока уровень позволяет).

## XP Curve
`XP(L→L+1) = 300 + 30·L` (`DungeonConfig._experienceBase/_experienceStep`), кап `_maxLevel = 50`.

| Ур. | Сумма XP | Ранов (≈450 XP) | Часов (≈3 рана/ч) |
|---|---|---|---|
| 5 | 1 500 | 3 | 1 |
| 10 | 4 050 | 9 | 3 |
| 20 | 11 400 | 25 | 8 |
| 30 | 21 750 | 48 | 16 |
| 40 | 35 100 | 78 | 26 |
| 50 | 51 450 | 114 | 38 |

Оценки — до плей-теста.

## XP Sources
Сейчас в коде: монстры (25–60) и +5 за выход. План:

| Источник | XP |
|---|---|
| Монстры | 25–60; в партии — каждому в 30 м полностью |
| Боссы | 150–300 |
| PvP-килл | 75 |
| Исследование | +5 контейнер, +10 новая комната, кап 100 за ран |
| Спуск на этаж | +50, убийства глубже ×1,25 за этаж |
| Выход | +50 и +50 % XP рана |
| Квесты (позже) | 300–1000 разово |

- Смерть: XP и уровень не теряются, теряется только бонус выхода.
- Анти-фарм: килл сопартийца и призванных — 0; бонус выхода пропорционален заработанному.

## After Cap
- **Слава** (аккаунт): XP сверх капа — бесконечные ранги, награды только косметика.
- Уровень — на персонажа; буст альтам +25 % XP за каждого капнутого персонажа (макс. +100 %).
- «Лига новобранцев»: уровни 1–29 (без подкласса), слияние с общей очередью, если сессия не набирается.
