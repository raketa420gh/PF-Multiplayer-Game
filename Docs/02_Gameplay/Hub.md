# Hub

Party hub: 3D-локация вместо меню-лобби, по ней ходят персонажем. Решение — DD-031. Пока только дизайн; в игре по-прежнему `LobbyScene`.

## Flow
```text
Создание персонажа → Выбор персонажа → Hub → рейд → Hub
```
- Создание персонажа — при первом входе и из окна выбора.
- Выбор персонажа — окно со списком персонажей игрока; после выбора грузится хаб.

## Кто в хабе
- Соло — в хабе только ты.
- Отряд — все члены отряда в хабе командира (создателя отряда). Хаб — его инстанс; вступивший в отряд переходит туда.
- Чужих игроков в хабе нет.

- Отряд собирается по четырёхзначному коду, как сейчас.
- Командир вышел из игры или из отряда → все члены отряда возвращаются каждый в свой хаб.

## Персонажи и стеш
- До 3 персонажей на аккаунт.
- Стеш у каждого персонажа свой.
- Плюс одна общая страница стеша на 100 клеток, видна всем персонажам аккаунта.
